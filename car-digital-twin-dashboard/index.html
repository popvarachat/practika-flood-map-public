DATA GOVERNANCE

Why this is a Digital Twin

Case + Document + Lineage + Quality
Case Twin

หนึ่ง CAR = หนึ่ง canonical entity มีวันที่ หน่วยงาน Category Severity Status และ Issue Detail

Document Twin

อ่าน PDF ทุก revision ลงฐานข้อมูล พร้อม Page Text, Form Widgets, Annotation และ File Attachment ไม่ได้หยุดแค่ชื่อไฟล์หรือ metadata

Source Lineage

Internal Twin เก็บ Drive lineage เต็มรูปแบบ ส่วน Public View ซ่อน URL / Drive ID และข้อมูลระบุตัวตน

Data Quality

ข้อมูลว่าง/ขัดแย้งถูก flag และภาพหรือ attachment ที่ text extraction อ่านไม่ครบถูกส่งเข้า Vision Review Queue แทนการเดา

Public-safe publication policy: ชื่อบุคคล อีเมล เบอร์โทร Drive URL/File ID, raw form fields และหลักฐานภายในไม่ถูกเผยแพร่ใน GitHub Pages
